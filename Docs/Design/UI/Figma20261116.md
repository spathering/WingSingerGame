- 06：按 `102:79 → 102:106 → 102:133 → 2:613 → 2:634 → 2:655 → 2:675 → 102:160 → 102:187` 顺序展示九页。点击画面前进，最后一页的选择关卡按钮进入选关页。前八页不提供提前选关。重新进入回到第一页。教程示意不创建游戏记录、不要求传感器达到阈值。暂停时从设置进入教程会保留原会话，返回后可继续；末页进入选关时才退出原关卡。

教程是用户要求的可点击图文教学；准备页的 Try the rhythm 仍启动既有真实输入练习，两者互不替代。传感器、键盘、练习和游戏统一使用新映射：**吸气下降 / W，呼气上升 / S，静息中轨**。USB 数值阈值、BLE 中心 / 偏差和连接协议不变。

## 实现和维护

使用 uGUI、TextMeshPro、现有 Darumadrop One 字体、PrimeTween 按钮反馈。背景、角色、图标等独立图层使用 Figma 导出的原始素材；没有把整张界面截图当作游戏 UI。按钮、滑条、开关、进度、文字保持原生可交互。`FigmaNodeTag` 保存设计节点编号，便于定位和重新验收。

资源位于 `Assets/Art/UI/Figma20261116/`。`Layout.json` 保存本次只读设计导出的尺寸、层级和本地素材名；不包含运行时远程地址。SVG 保留源文件，并光栅化为 PNG 供 Unity 原生 Sprite 使用。玻璃面板使用圆角网格和局部背景模糊采样；前景、角色、文字和控件仍为独立对象。

正式页 Prefab 保留原来的路径和 GUID；增加 `15_Tutorial.prefab`，路由枚举在既有值之后追加。`14_HardwareSettings.prefab` 保留。正式场景继续为 `BreathDemo`，统一关卡管理器通过实例根对象 `SetActive` 切换，界面不会加载新游戏场景。

`UIPageViewport` 按 2420×1668 设计空间适配，菜单背景覆盖实际画面。游戏页隐藏设计稿示意背景 / 飞行物体，显示真实场景、角色、星星和千纸鹤。新 HUD 用真实路线给出呼吸方向，不使用设计稿中的固定分数、固定关卡或固定连接状态。

中景 `Looping Foreground.sizeMultiplier` 从 2 调到 2.7，放大 35%；保持世界底边、差速参数和相位不变。镜头与原有开场 / 中场视频流程保持现有配置。

注意：既有路线字段 `inhaleSeconds` / `exhaleSeconds` 是历史命名，当前仍分别表示上轨 / 下轨停留。第 1 关继续上轨 2 秒、下轨 3 秒，因此界面显示吸气 3 秒、呼气 2 秒；不要为匹配新输入方向交换路线配置。

## 后续细节修正

- 上方呼吸提示与下方指导文案读取 `BreathLevel.SampledGuideTime`，直接复用纸鹤实际呈现时采用的采样时间；不再使用落后于纸鹤的玩家路线时钟。上轨为呼气 / S，下轨为吸气 / W，中轨自然呼吸；开场和拉近镜头期间显示 Get ready。正确性反馈仍按玩家当前位置的路线判定，收集和计分规则不变。
- 2–12 关统一锁定缩略图透明度 0.28、灰色描边、编号色、锁图标尺寸与位置；不保留 2/3 的完成样式或 4 的选中样式。
- 关卡卡片仅更新选中状态和关卡说明；`ContinueSelection` 才进入准备页，并再次检查关卡可用性。仅第一关开放。
- 左侧量表只读取当前实际启用的硬件输入：BLE 使用接收器的 5 点均值，静息基准暂定 1300 mV，目标偏差 100 mV；低于 1200 判定吸气，1200–1400（含边界） 为静息，高于 1400 判定呼气。边界保持原协议的严格判定。
- 量表显示相对静息中心的绝对偏差；基准线为 100% 目标，全条高度为 200%。低于目标灰色、实际判定达标后绿色；同时显示传感器数值和目标偏差。目标与硬件页设置同步，USB 模式自动使用原有 400/1000 阈值，不强套 BLE 基准。
- 无连接、无新鲜样本、阈值无效或实际使用键盘 / 外部调试输入时，量表灰显并清空，显示 NO SENSOR。键盘不模拟量表达标。
- `Temp/WingSingerFigma.request` 的 `refine` 只定向生成选关和游戏 HUD 两个 Prefab 并更新对应场景引用，不重建其他页面或改动树木 / 视频配置。

## 橙色按钮与色彩调整

橙色主按钮统一为不透明暖橙 `#C77A3B`，正常和悬停均保持 alpha=1，按下时适度变暗；禁用状态继续使用既有灰显。布局与路由不变。

关卡共享 `BreathDemoVolume` 仅新增 / 设置 ColorAdjustments 的 Saturation=+15，曝光、对比度、色相不额外覆盖。三个已有质量档位沿用同一个场景 Volume，不变更 Renderer Feature。菜单插画、背景、模糊底图和中场视频通过共享 `Resources/WingSingerUIArt.mat` 采用 1.15 倍饱和度，保留原透明通道与 UI 遮罩；源图片 / 视频不重编码，文字和按钮不使用插画调色材质。

`FigmaVisualStyle` 可定向更新已有 Prefab 的颜色 / 材质，后续 Figma 页面生成也复用它；无需整批重建 UI 层级。此轮沿用现有界面验证，263 项通过，已检查首页、准备页和实际关卡截图；没有新增低影响样式专用测试。
